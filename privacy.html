隐私与广告

本说明适用于 UI 风格图鉴。更新日期：2026 年 9 月 24 日。

当前版本未启用第三方广告，不会加载 AdSense 脚本。

浏览器内保存的信息

网站把收藏、网站主题、卡片大小、预览配色和最近查看的风格等偏好保存在当前浏览器的本地存储中。网站功能本身不要求注册或登录；搜索和提示词组合在浏览器内处理，没有把这些输入主动提交给本站业务服务器。

你可以通过浏览器的“清除网站数据”删除这些偏好。收藏不是云端同步数据；清理后可能无法恢复。

服务器与访问记录

本站由 GitHub Pages 托管。GitHub 可能为提供网站和安全排查处理 IP 地址、访问时间、请求路径、浏览器标识和错误信息；具体处理及保存期限以 GitHub 隐私声明为准。离线打开文件时不经过网站托管服务器。

第三方广告

启用后，本站计划使用 Google AdSense。在访问获准的正式域名、满足广告加载条件时，Google 及相关合作伙伴可能通过 Cookie、本地存储、网络信标和 IP 地址等技术处理访问与广告信息，用于提供广告、衡量效果以及防止欺诈。广告可能基于你对本站或其他网站的访问情况进行个性化；实际处理受你的选择和适用规则约束。

第三方具体处理方式见 Google 如何使用合作伙伴网站的信息、Google 隐私权政策。你可以通过 Google 我的广告中心调整相关广告设置。

同意与退出

正式启用广告前，运营者需要在 AdSense 的“隐私权和消息”中发布适用的地区消息，或使用符合要求的认证同意管理平台。适用时，访问者通过该平台提供的入口同意、拒绝或重新调整选择。本页面不是同意弹窗，也不会把“继续浏览”视为同意。

站点自身的广告模块识别浏览器的 Global Privacy Control 信号；检测到该信号时不会主动加载 AdSense。广告服务被拦截或无法加载，不影响浏览、收藏、对比和提示词复制。

点击外部链接后，将适用对应网站的规则。若后续加入账号、统计、付费服务或其他数据处理，本说明需同步更新，不会以当前说明替代新增功能所需的告知。
