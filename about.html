THE INTERFACE ATLAS

关于本站

UI 风格图鉴是一个用于比较界面视觉语言的工具：通过实时 CSS 样本浏览风格、查看浅色与深色配色、并排对比，以及复制设计提示词。

内容与演示

当前收录 79 种风格，包括 50 种主风格与 29 种补充变体。预览中的业务数据均为演示数据，示例不代表对应品牌或设计系统的官方界面。

风格目录与部分描述、关键词来源于 Next Level Builder 的 UI/UX Pro Max Skill；网站预览、交互与中文辅助说明在本项目中维护。上游项目采用 MIT 许可证，许可证声明已随网站提供。UI 风格图鉴不是该 Skill 的官方网站。

广告与使用

核心浏览、收藏、对比与提示词复制不会以点击广告为条件。接入的广告与风格样本分区展示，并明确标识，不代表本站对广告产品的背书。

当前版本未启用第三方广告，不会加载 AdSense 脚本。
